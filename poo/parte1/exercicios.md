# 📝 Lista de Exercícios - Programação Orientada a Objetos com C#

Esta lista de exercícios foi elaborada para praticar os fundamentos de POO com C#, incluindo criação de classes, objetos, métodos e membros estáticos.

---

## 🔹 Parte 1: Classes, Objetos e Atributos

1. Crie uma classe `Triangulo` com os atributos `A`, `B` e `C`. Leia as medidas de dois triângulos e determine qual possui a maior área. [Link](./exercicios/Ex01)
2. Crie uma classe `Retangulo` com atributos `largura` e `altura`. Adicione métodos para calcular área, perímetro e diagonal. [Link](./exercicios/Ex02)
3. Crie uma classe `Funcionario` com atributos `Nome`, `SalarioBruto` e `Imposto`. Adicione um método que calcule o salário líquido e outro que aumente o salário com base em uma porcentagem. [Link](./exercicios/Ex03)

---

## 🔹 Parte 2: Métodos

4. Adicione à classe `Triangulo` um método `Area()` que retorna a área usando a fórmula de Heron. [Link](./exercicios/Ex01)
5. Adicione à classe `Funcionario` o método `ToString()` para retornar os dados do funcionário formatados. [Link](./exercicios/Ex03)
6. Crie uma classe `Aluno` com três notas (trimestres). Calcule a média final e informe se o aluno foi aprovado (nota mínima: 60). Caso reprovado, informe quantos pontos faltaram. [Link](./exercicios/Ex06)

---

## 🔹 Parte 3: Membros Estáticos

7. Crie uma classe `Calculadora` com métodos estáticos para: [Link](./exercicios/Ex07)

   - Calcular a circunferência de um círculo
   - Calcular o volume de uma esfera
   - Mostrar o valor de PI

8. Crie uma classe `ConversorDeMoeda` com um método estático que: [Link](./exercicios/Ex08)
   - Converte um valor em dólares para reais
   - Aplica um IOF de 6%

---

## 🔹 Desafio Extra

9. Modele uma classe `Produto` com os seguintes recursos: [Link](./exercicios/Ex09)
   - Atributos: `Nome`, `Preco`, `Quantidade`
   - Métodos: `ValorTotalEmEstoque()`, `AdicionarProdutos()`, `RemoverProdutos()`
   - Sobrescreva o método `ToString()` para exibir os dados do produto formatados

---

Esses exercícios ajudam a consolidar a criação de classes, instância de objetos, encapsulamento e o uso de membros estáticos em C#.
